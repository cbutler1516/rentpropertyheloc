# RentPropertyHELOC.com

Marketing site for rental-property HELOC programs built with Next.js App Router, TypeScript, and Tailwind CSS.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Deploy to [Vercel](https://vercel.com) with the default Next.js preset. No extra configuration required.

## Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- TypeScript
